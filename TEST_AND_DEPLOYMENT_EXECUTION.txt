TROUBLESHOOTING QUICK GUIDE
================================================================================

ISSUE: GitHub Actions job fails
SOLUTION: Check job logs, fix issue, push again

ISSUE: Firebase deployment fails
SOLUTION: Check secrets, verify Firebase project, run firebase:login:ci

ISSUE: Tests fail
SOLUTION: Run locally (npm test), fix failing tests, push again

ISSUE: Build fails
SOLUTION: Check TypeScript errors (npm run type-check), fix, push

ISSUE: Firestore rules rejected
SOLUTION: Test locally (firebase rules:test), fix rules, push

ISSUE: Application not accessible
SOLUTION: Check Firebase hosting status, verify custom domain settings

See COMPLETE_DEPLOYMENT_GUIDE.md for detailed troubleshooting
