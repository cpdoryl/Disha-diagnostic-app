### 1. ✅ detectEarlyWarnings (80 LOC)
**File:** `functions/src/firstOpinion/detectEarlyWarnings.ts`

**Type:** HTTP Callable Cloud Function (onCall)  
**Trigger:** On-demand (admin-initiated)  
**Access:** Admin only (role-based gating)

**Functionality:**
- Detects early warnings for a specific assessment cycle
- Analyzes current health index and metrics
- Assigns warning level (GREEN/YELLOW/RED/CRITICAL)
- Calculates risk score (0-100)
- Generates interpretation string
- Persists warning to Firestore

**Data Flow:**
```
Admin Call
    ↓
Authentication Check
    ↓
Admin Authorization Check
    ↓
Fetch Cycle Scores
    ↓
Determine Warning Level (threshold-based)
    ↓
Calculate Risk Score (with gap escalation)
    ↓
Store to Firestore (warnings/latest)
    ↓
Return Response
```

**Response Structure:**
```typescript
{
  success: true,
  warning: {
    level: "CRITICAL",
    score: 85.5,
    interpretation: "Critical: Health index 35 requires immediate intervention",
    timestamp: "2026-08-26T..."
  }
}
```

**Usage:**
```typescript
const detectWarnings = httpsCallable(functions, 'detectEarlyWarnings')
const result = await detectWarnings({
  schoolId: 'school_001',
  cycleId: 'cycle_1_2026'
})
```

### 2. ✅ onCycleCompletion (75 LOC)
**File:** `functions/src/firstOpinion/onCycleCompletion.ts`

**Type:** Firestore Trigger (onWrite)  
**Trigger:** Document write to `schools/{schoolId}/assessmentCycles/{cycleId}`  
**Execution:** Automatic (no user action required)

**Functionality:**
- Auto-triggers when cycle scores are calculated
- Detects warning level from updated health index
- No authentication/authorization needed (backend operation)
- Stores warning data for real-time dashboard display
- Tags as `autoGenerated: true` to distinguish from manual triggers

**Data Flow:**
```
Score Recalculation Cloud Function
    ↓
Updates cycle document with scores
    ↓
Firestore onWrite trigger fires
    ↓
Extract health index and gap
    ↓
Determine warning level
    ↓
Calculate risk score
    ↓
Store to warnings/latest collection
    ↓
Dashboard listener fires (real-time update)
```

**Trigger Conditions:**
```typescript
// Triggers on ANY write to:
schools/{schoolId}/assessmentCycles/{cycleId}

// If has scores, generates warning
if (data.scores && data.scores.healthIndex !== undefined) {
  // Generate & store warning
}
```

**Storage Location:**
```
schools/
  ├─ {schoolId}/
     └─ assessmentCycles/
        ├─ {cycleId}/
        │  └─ warnings/
        │     ├─ latest (LIVE - dashboard reads this)
        │     └─ history (archived warnings)
```

**Data Stored:**
```typescript
{
  level: "CRITICAL",
  score: 85,
  interpretation: "Critical: Health...",
  healthIndex: 35,
  gap: 25,
  s_sub: 50,
  m_obj: 50,
  quadrant: "PERCEPTION_BETTER",
  respondentCount: 20,
  createdAt: Timestamp.now(),
  autoGenerated: true
}
```
