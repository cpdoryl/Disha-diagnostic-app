## 🔧 **TROUBLESHOOTING**

### **Problem: Can't Find "Create Assessment" Button**

```
SOLUTION 1: Look in different locations
  ✓ Check center of page
  ✓ Check top navigation menu
  ✓ Check sidebar (if logged in)
  ✓ Check top-right corner

SOLUTION 2: Button might be hidden
  ✓ Scroll down to see if button is below
  ✓ Check if page fully loaded
  ✓ Wait 2-3 seconds for page to complete loading

SOLUTION 3: Try keyboard shortcut
  ✓ Press Tab key repeatedly to navigate to button
  ✓ When button is focused (highlighted), press Enter

SOLUTION 4: Check permissions
  ✓ Make sure you're logged in as Admin
  ✓ Check if you have "Create Assessment" permission
  ✓ Try refreshing page (F5)
```

### **Problem: Modal Doesn't Appear After Click**

```
SOLUTION 1: Wait longer
  ✓ Wait 2-3 seconds for modal to load
  ✓ Check if browser is processing

SOLUTION 2: Check browser console
  ✓ Press F12 to open Developer Tools
  ✓ Click "Console" tab
  ✓ Look for red error messages
  ✓ Note any errors and report

SOLUTION 3: Try again
  ✓ Close any open modals (press Escape)
  ✓ Click the button again
  ✓ Wait for modal to appear

SOLUTION 4: Refresh page
  ✓ Press F5 to refresh
  ✓ Wait for page to load
  ✓ Try clicking button again
```

### **Problem: Form Shows Error After Filling**

```
COMMON ERRORS:

Error: "Assessment Name is required"
  FIX: Make sure you typed in the Assessment Name field
  FIX: Don't leave it blank
  FIX: Click in field and type again

Error: "Please select a school"
  FIX: Click the School dropdown
  FIX: Select "Test School Alpha"
  FIX: Make sure field shows the selection

Error: "Invalid input"
  FIX: Clear the field
  FIX: Type again carefully
  FIX: Avoid special characters (! @ # $ %)
  FIX: Use letters, numbers, spaces, hyphens only

Error: "School not found"
  FIX: The school you selected might not exist
  FIX: Choose a different school from dropdown
  FIX: Ask admin to verify school exists in system
```
