## 🆘 **TROUBLESHOOTING**

### **Problem: Button Not Visible**

```
SOLUTION 1: Scroll down
  ACTION: Press Page Down or scroll with mouse wheel
  REASON: Button might be below fold on smaller screens
  
SOLUTION 2: Refresh page
  ACTION: Press F5 to reload
  REASON: Page might not have loaded completely
  
SOLUTION 3: Check zoom level
  ACTION: Press Ctrl+0 to reset zoom
  REASON: Page might be zoomed in too much
```

### **Problem: Button Click Not Working**

```
SOLUTION 1: Try again
  ACTION: Move mouse away, then click again
  REASON: First click might not have registered
  
SOLUTION 2: Click "Launch Platform" instead
  ACTION: Click the blue button in top-right
  REASON: Alternative path to assessments
  
SOLUTION 3: Check internet connection
  ACTION: Look at browser connection status
  REASON: Network issue might prevent response
```

### **Problem: Page Doesn't Load After Click**

```
SOLUTION 1: Wait longer
  ACTION: Wait 5-10 seconds
  REASON: Page might be loading slowly
  
SOLUTION 2: Check browser console
  ACTION: Press F12, click Console tab
  REASON: Error message might explain issue
  
SOLUTION 3: Open Developer Tools Network
  ACTION: F12 → Network tab → Refresh
  REASON: See what files failed to load
```
