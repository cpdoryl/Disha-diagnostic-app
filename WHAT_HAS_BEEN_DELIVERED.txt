                    7-LAYER SCORING SYSTEM
================================================================================

Layer 1:  Question Weight Mapping           → Input (1-10 scale)
Layer 2:  Challenge Score Calculation       → Average of questions
Layer 3:  Subjective Base Score             → 0-100 scale
Layer 4:  Objective Multiplier (4 metrics)  → 0.5-1.0 scale
Layer 5:  Delusion Penalty                  → 0-30 point deduction
Layer 6:  Health Index Calculation          → 0-100 scale
Layer 7:  Risk Quadrant Classification      → 4 quadrants

FORMULA: H = (S_sub × M_obj) - P_mismatch

Where:
  S_sub = Subjective base score (0-100)
  M_obj = Objective multiplier (0.5-1.0)
  P_mismatch = Delusion penalty (0-30)

4 RISK QUADRANTS:
  🟢 Elite Equilibrium (75-100)        → Market leader, sustainable
  🟡 Hidden Excellence (50-74)          → Good fundamentals, weak branding
  🟠 Delusional Comfort (25-49)        → Poor fundamentals, inflated perception
  🔴 Critical Collapse (0-24)          → Severe issues, emergency needed
