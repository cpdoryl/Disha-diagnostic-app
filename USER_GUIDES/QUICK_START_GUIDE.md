# 🚀 DISHA Diagnostic Engine - Quick Start Guide

**Welcome to DISHA!**

This guide will help you get started with the DISHA Diagnostic Engine in just 5 minutes.

---

## ⚡ 5-Minute Quick Start

### Step 1: Access the Application (1 min)
```
1. Open your browser
2. Go to: https://disha-diagnostics.web.app/
3. Application loads automatically
```

### Step 2: Create Your First Assessment (2 min)
```
1. Click "Create Assessment" button
2. Enter assessment name (e.g., "School Health Check 2026")
3. Select your school
4. Review the 14 dimensions (auto-selected)
5. Click "Save Assessment"
```

### Step 3: Invite Stakeholders (1 min)
```
1. View assessment link
2. Share with teachers via email
3. Share with parents (via school portal)
4. Share with students (if applicable)
5. Track responses on dashboard
```

### Step 4: View Results (1 min)
```
1. Open dashboard
2. See real-time response count
3. View dimension scores
4. Generate report
5. Download as PDF
```

## 🎯 What is DISHA?

**DISHA** = **D**iagnostic **I**nstitutional **S**trength & **H**ealth **A**ssessment

A comprehensive system to evaluate school health across 14 dimensions by collecting feedback from multiple stakeholders (teachers, parents, students, administrators).

### The 14 Dimensions
```
1. Leadership & Governance         8. Staff Development
2. Teaching & Learning             9. Quality Assurance
3. Infrastructure & Resources     10. Financial Management
4. Student Support Services       11. Health & Safety
5. Community Engagement           12. Equity & Inclusion
6. Curriculum & Assessment        13. Innovation & Change
7. Technology Integration         14. Student Outcomes
```

## 🎬 Common Workflows

### Workflow 1: School Self-Assessment

**Time: 30 minutes**

```
Step 1: Admin Creates Assessment (5 min)
  ✅ Open DISHA application
  ✅ Click "Create Assessment"
  ✅ Name it "School Health Diagnostic 2026"
  ✅ Select school
  ✅ Save

Step 2: Share Assessment Link (5 min)
  ✅ Copy assessment link
  ✅ Email to teachers
  ✅ Share in parent WhatsApp group
  ✅ Post for students (if applicable)

Step 3: Collect Responses (15 min)
  ✅ Teachers respond (5-10 min each)
  ✅ Parents respond as available
  ✅ Students respond (if age-appropriate)
  ✅ Admin responds

Step 4: Review Results (5 min)
  ✅ Open dashboard
  ✅ Check response counts
  ✅ View dimension scores
  ✅ Note any gaps
```

### Workflow 2: Using First Opinion Engine

**Time: 10 minutes**

```
Step 1: Start Engine (1 min)
  ✅ Click "First Opinion Engine"
  ✅ Read instructions

Step 2: Answer Questions (8 min)
  ✅ Answer 15 challenge questions
  ✅ Based on your school's situation
  ✅ Each question takes ~30 seconds

Step 3: Get Results (1 min)
  ✅ View predicted health score
  ✅ See early warning flags
  ✅ Read recommendations
  ✅ Download report
```

### Workflow 3: Generate School Report

**Time: 5 minutes**

```
Step 1: Open Completed Assessment (1 min)
  ✅ Go to assessments list
  ✅ Click on completed assessment
  ✅ Dashboard loads

Step 2: Generate Report (3 min)
  ✅ Click "Generate Report"
  ✅ Select sections to include
  ✅ Review preview

Step 3: Download (1 min)
  ✅ Click "Download PDF"
  ✅ Save to computer
  ✅ Share with stakeholders
```

## 💡 Tips & Tricks

### For Teachers
```
✅ Respond honestly - your feedback is valuable
✅ Take 5-10 minutes to answer carefully
✅ Focus on your direct experience
✅ Feel free to add comments
```

### For Parents
```
✅ Share your observations from home
✅ No technical knowledge needed
✅ Response takes 5-10 minutes
```

### For Admins

## ❓ Troubleshooting

### "I can't access the link"
```
Solution:
  1. Check internet connection
  2. Try a different browser
  3. Clear browser cache
  4. Contact your school admin
```

### "Assessment link not working"
```
Solution:
  1. Copy full URL carefully
  2. Check for extra spaces
  3. Share via email (prevents truncation)
  4. Admin can resend link
```

### "My responses aren't saving"
```
Solution:
  1. Check internet connection
  2. Wait for "Saved" confirmation
  3. Try refreshing page
  4. Use desktop if on mobile
```

### "Can't see all respondents"
```
Solution:
  1. Scroll down to see all types
  2. Refresh page
  3. Check filter settings
  4. Clear browser cache
```
